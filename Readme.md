# 🎯 AI Interview Preparation System

A web-based application built with **Streamlit** and **Machine Learning** to help students evaluate their coding skills, identify weak topics, and get a personalized learning roadmap.

## 🚀 Features
- **Student Profile:** Save target role, branch, and academic year.
- **Skill Assessment:** Rate skills across DSA & Core CS subjects (Arrays, Linked List, Stack, Queue, DBMS, OS).
- **Analytics Dashboard:** Visual bar charts and automatic weak/strong topic detection.
- **AI Roadmap:** 4-week structured study plan for weak topics.
- **Interview Question Generator:** Practice topic-wise coding questions.
- **Readiness Prediction:** Uses a Decision Tree Classifier to predict interview readiness.

## 🛠️ Tech Stack
- **Frontend/UI:** Streamlit
- **Data Analysis:** Pandas, Matplotlib
- **Machine Learning:** Scikit-Learn
